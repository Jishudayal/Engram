# Examples

Start with:

1. `quickstart.py` — minimal memnotary loop
2. `customer_support_bot.py` — realistic memory cleanup scenario
3. `langchain_retriever.py` — LangChain VectorStore integration

All examples run with `pip install memnotary` (or `pip install "memnotary[langchain]"` for the third). No API key or external backend required.
